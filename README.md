# AI Agent Red Team Simulator

An AI security testing platform that evaluates autonomous AI agents for vulnerabilities such as:

- Prompt Injection
- Secret Leakage
- Memory Poisoning
- Unsafe Tool Usage
- Excessive Permissions

The platform uses Hermes as an orchestration layer to execute attack workflows against AI agents and generate security reports with remediation guidance.

## MVP

- Vulnerable test agent
- Prompt injection testing
- Secret leakage testing
- Automated reporting
